# סגירה מאוחדת של UI-4 — מסכי חשבון וניהול

**תאריך:** 12.10.2026. העבודה בענף `fix/security-foundation-20261011`, ב־PR #1 טיוטה בלבד. **UI-4 הושלם טכנית בקוד ובבדיקות**, לא נפרס ולא הוכרז כמוכן לייצור. SHA ותוצאת CI המדויקים מאומתים בדוח המסירה לאחר push.

## חיבור, הרשאות ותצוגה

ששת התחומים שולבו בממשקי השרת הקנוניים עם owner_context מול principal עצמאי. root מפורש או tenant/downline קיימים בלבד, allow-lists, queries bounded, no-autoflush ו־timeouts. Decimal strings ו־null נשמרים; חסר אינו אפס. מעבר auth/id/tenant/role מסלק data/pending ישנים ו־AbortSignal מגיע ל־transport. אין write replay, polling או retry בלתי מוגבלים.

navy/slate/cyan, מעטפת אחת, טפסים ופקדים עם labels/focus/alerts, טבלאות בגלילה פנימית וטקסט ארוך נשבר. הצ׳אט אינו מכסה מסכי מנהל, ויעד תמיכה אמיתי נשמר. UI-5 עדיין מיועד לאחידות עיצוב ומובייל רוחבית; החבילה אינה מחליפה אותו.

## ראיות ותיקונים

- PostgreSQL זמני נבנה מראשי Alembic האמיתיים `20261012_000001`; ששת נתיבי HTTP דרך factory אמיתי עברו, לצד אורח 401, תפקיד לא מורשה 403 ושמירת Users update/reset/deactivate.
- שש תגובות HTTP אמיתיות סינתטיות עברו דרך ממפי frontend מול principal עצמאי; owner זר נדחה בכל תחום.
- נסגרו ממצאי נעילת User מול DISTINCT, stale CRM mutations/refreshes, מטבע budget מומצא ומעטפת LeadDetails כפולה, עם ביקורת עצמאית.
- הרגרסיה הכוללת חשפה guard affiliate שהושמט, tree-path שגוי שחזר 503 ו־seams של בדיקות legacy. החסימה וה־400/rollback שוחזרו; הבדיקות עודכנו בלי להסיר בדיקות פרטיות/no-provider/no-DML/capability.
- שחזור ממוקד מצא route-id string שהגיע לחוזה API מספרי: המרה קנונית תחומה נוספה רק בגבול React Router. מזהי API ותשובות נותרו קשיחים. שלושה מרוצי App/React/Router של create/update/delete מול החלפת user/tenant/role עברו ללא state/toast/navigation/refresh ישנים.

## מה נותר

UI-1, UI-2 ו־UI-4 סגורים טכנית. **UI-3** עדיין פתוח להחלטות business/legal ותוכן דינמי; **UI-5** עיצוב/מובייל רוחבי ו־**UI-6** קבלה מלאה של מפת הנתיבים והפעולות נותרו בתוכנית. הדוחות ההיסטוריים מתארים את מצב כל חבילה בעת מסירתה; מסמך זה ותוכנית ההשלמה הם מצב הסגירה העדכני.

ארנק/MT5/ספקים חיים/תשלום/אימייל לא הופעלו. אין anti-fraud כספי מלא, פדיון מאומת או מדיניות עמלה פעילה שהומצאה; 15%, בסיס עמלה, hold, מינימום ורשת USDT דורשים החלטה מאושרת ואימות נפרד. אין שינוי פרטי חברה, jurisdiction או מדיניות משפטית מתוך שתיקה.

**אין merge/deploy, גישה לייצור או שינוי נתוני ייצור.** פריסה היא פעולה נפרדת לאחר שערי הסיום, אימות קונפיגורציה, גיבוי בר־שחזור, rollback ואישור מפורש. Push ו־CI אינם פריסה.
