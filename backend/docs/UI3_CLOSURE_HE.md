# סגירת UI-3 — השלמות ללא ארנק או MT5

**עודכן:** 12.10.2026. המשך באותו ענף ו־PR טיוטה, ללא שינוי ייצור, ספק, הרשאות חשבון, merge או deploy.

## מה נסגר בקוד בחבילה זו

ה־Google Analytics הבלתי מותנה מתוך `frontend/index.html` הוסר. החבילה אינה מעבירה את המדידה לספק אחר ואינה מציגה כפתור consent או הפעלה ללא ספק פעיל. נוסף `AnalyticsStatus` ב־CookiePolicy עם הסבר טכני וקישור פוטר ל־`/cookie-policy#analytics-status`. ה־panel אומר במפורש: המדידה האופציונלית המסוימת אינה נטענת בגרסה זו, האחסון לצורך sign-in נפרד, אין מחיקת נתוני חשבון או עוגיות מביקורים קודמים, ואין אישור למסמך הפרטיות.

טקסט מדיניות העוגיות הישן נשמר לצורך review ומסומן כטיוטה שלא אושרה וכלא־מאמת תצורת איסוף נוכחית; לא הומצאו זכויות או ספקים חדשים. אין כאן מפת כל איסוף המידע, הסרה של Google Fonts או בדיקת ייצור. ההשלמה אינה מוכנות משפטית, אסמכתה לשירות שאושר או UI-3 מושלם.

## למה לא נטען ״רוב״ בלי פירוט

הסקירה הקודמת מכסה את מקורות כל 60 מודולי המסך ותיקוני המלל הציבורי. נותרים פרטי העסק ומקור מאושר לחמשת עמודי policy: תנאים, פרטיות, סיכון, החזרים ועוגיות. בנוסף נדרשות החלטות לכללי תוכניות ותנאי אפיליאט, וסקירת תוכן דינמי של מאמרי בלוג/עזרה ותיאורי תוכניות. דוחות העמודים הקודמים נשמרו; אין צורך לסקור מחדש את אותו קוד כדי לזהות שוב אותם פערים.

פרטי שם חברה, מדינה, כתובת קשר, jurisdiction, refund/retention/SLA, הסכמה בתהליך הרשמה וכללי drawdown/EA אינם נגזרים מעצם קיום קוד ישן. הצעת 14 ימי hold ו־$50 לאפיליאט לא אושרה; לא קובעים אותה כמוצר חי. אפשר להכין טיוטה עם החלטות חסרות, אבל היא אינה מסמך מאושר ואינה מסיימת את UI-3. ההחלטות אינן מחייבות API של ארנק או MT5.

ביקורת התוכן הדינמי צריכה מקור תוכן ציבורי מאושר או ייצוא ממוקד, ולא קריאת DB לקוחות גורפת. בקשת קריאה בלבד עדיין ממתינה. `GET /blog/posts/<slug>` מגדיל מונה צפיות, ולכן אינו מקור read-only לאיסוף audit. אין קריאת רשומות ייצור בחבילה זו.

## תנאי סיום UI-3

מסמכי המדיניות וכללי המוצר יותאמו לעובדות ולהחלטות מפורשות; הנוסח יקבל אישור מתאים לפני שיוצג כמדיניות מחייבת. תוכן דינמי ייסקר ממקור שהותר, עם רישום מה נקרא ומה חסר. דפי התוכן וההסכמה יציגו אותו מקור מאושר, ללא נתונים/זכויות/תאריכים מומצאים. רק אז מסמנים UI-3 סגור. מצב UI-4/5/6 נפרד; אף אחד מהם לא נסגר בחבילת מדידה קטנה.

## מקורות ההחלטה הטכנית

[Google — About consent mode](https://support.google.com/analytics/answer/10000067?hl=en) מבדיל בין Basic שבו תג אינו נטען לפני בחירה, לבין Advanced שעשוי לשלוח pings גם בלי cookies. בחבילה זו לא מוטמע אף adapter: התג הוסר ומדידה זו אינה פעילה.

[Google — Configuration reference](https://developers.google.com/analytics/devguides/collection/ga4/reference/config) מתעד `send_page_view`, `page_location`, referrer ו־advertising signals. אם תוחזר מדידה בעתיד, נדרשות תצורה מאושרת ובדיקות בחירה/שלילה ונתונים מוגבלים; לא מעתיקים את התג הישן בחזרה ללא פתרון זה.

## בדיקות

בדיקות React אמיתיות לפאנל, גרף המקור ללא טעינת gtag/dataLayer וליעד anchor הקיים; כל בדיקות frontend ובנייה. אין backend שינוי או שינוי סכמות. בדיקות CI וה־SHA הסופי מתועדים בדוח המסירה. no active-project diagnostics בעותק GitHub הקיים אינו clean LSP; שימשו בדיקות המקור, Vite/esbuild ו־build הקיימים במקום אתחול אתר חדש.
